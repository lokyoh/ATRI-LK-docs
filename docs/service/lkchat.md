# 聊天

## 服务信息

- **服务名**：聊天
- **说明**：ATRI进行聊天处理的插件
- **限定权限**：无

## 命令列表

- **/亚托莉语音**：随机亚托莉语音
- **/聊天.添加解释**（主人）：为词语添加解释，用法：/聊天.添加解释 词语 解释 重要度(0-100越大越重要)
- **/聊天.查看记忆**：查看亚托莉对你的记忆
- **/聊天.删除记忆**：删除亚托莉对你的记忆，用法：/聊天.删除记忆 序号

## 功能说明

### 聊天功能

在群聊中@机器人或回复机器人消息即可触发聊天功能。聊天功能使用Agent智能体系统，支持：

- 长期记忆：记住与用户的对话内容
- 用户画像：根据交互构建用户偏好
- 词语解释：解释特定词语或概念
- 网络搜索：搜索实时信息（需配置）

### 戳一戳

当用户戳一戳机器人时，会随机触发以下反应：

- 10%概率：发送亚托莉语音
- 20%概率：发送亚托莉表情包
- 40%概率：发送随机回复消息
- 30%概率：回戳用户

### 词语解释

主人可以使用 `/聊天.添加解释` 命令为特定词语添加解释，Agent在聊天时会参考这些解释。格式为：

```
/聊天.添加解释 词语 解释 重要度(0-100)
```

重要度越高，Agent在遇到该词语时越会参考这个解释。

### 记忆管理

用户可以查看和删除Agent对自己的记忆：

- `/聊天.查看记忆`：查看Agent记住的所有关于你的记忆
- `/聊天.删除记忆 序号`：删除指定序号的记忆

记忆会随着对话自动积累，Agent会在后续对话中引用这些记忆。
