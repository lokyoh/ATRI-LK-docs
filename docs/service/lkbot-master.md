# 主人

## 服务信息

- **服务名**：主人
- **说明**：ATRI的综合性插件的主人专用指令部分
- **限定权限**：主人

## 命令列表

- **/强制改名**：将指定用户名称修改成指定名称，用法：/强制改名 @用户 \[名称]
- **/所有用户**：列出所有的用户
- **/强制绑定已有账号**：强制将目标用户绑定到指定主账号，用法：/强制绑定已有账号 \[目标用户ID] \[主账号ID]
- **/强制解绑**：强制解除目标用户的账号绑定，用法：/强制解绑 \[目标用户ID]
