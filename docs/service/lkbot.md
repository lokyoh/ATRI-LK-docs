# 用户

## 服务信息

- **服务名**：用户
- **说明**：ATRI的综合性用户系统插件
- **限定权限**：无

## 命令列表

- **/我的信息**：查询自己的信息
- **/我的背包**：查看背包中的内容
- **/物品查询**：查询指定物品信息
- **/使用**：使用指定物品,'全部物品'使用全部,'物品*n'使用n个物品
- **/回收**：将指定数量物品换成ATRI币,'全部物品'回收全部,'物品*n'回收n个物品
- **/商店列表**：列出所有商店
- **/商品列表**：列出指定商店的商品列表
- **/购买**：从指定商店中购买指定数量的商品，用法：/购买 \[商店名] \[物品|物品*n]
- **/改名**：用改名卡修改自己的名称
- **/绑定**：为自己绑定一个名称
- **/获取绑定密钥**：私聊获取一个小时有效的一次性账号绑定密钥
- **/绑定已有账号**：用绑定密钥将当前账号关联到已有主账号
- **/解绑**：解除当前账号与主账号的绑定关系
- **/排行**：查看排行
- **/账号信息**：查看当前账号的信息
