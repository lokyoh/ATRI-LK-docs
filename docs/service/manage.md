# 管理

ATRI 的综合管理服务，负责封禁、群控、权限与插件管理。

## 服务信息

- **服务名**：管理
- **说明**：控制 ATRI 的各项服务
- **限定权限**：主人

## 命令列表

- **/封禁用户**：阻止目标用户使用 ATRI
- **/解封用户**：恢复指定用户的使用权限
- **/封禁群**：阻止目标群所有人使用 ATRI
- **/解封群**：恢复目标群的使用权限
- **/全局控制**：全局启用/禁用某个服务
- **/控制**（管理员可用）：针对当前群启用/禁用某个服务
- **/白名单**：切换某个服务的白名单状态
- **/追踪、/track**：根据报错 ID 查询对应错误信息
- **/同意好友**：根据申请码通过好友申请
- **/拒绝好友**：根据申请码拒绝好友申请
- **/同意邀请**：根据申请码同意入群邀请
- **/拒绝邀请**：根据申请码拒绝群邀请
- **对用户 X 启用 Y / 对用户 X 禁用 Y**：针对单一用户启用/禁用某项服务
- **/好友申请列表**：查看当前的好友申请列表
- **/群邀请列表**：查看当前的群邀请列表
- **/撤回**（需回复消息并引用）：撤回 ATRI 已发送的消息
- **/nb.添加插件**：从 NoneBot 商店安装插件
- **/nb.移除插件、/nb.删除插件、/nb.卸载插件**：移除插件
- **/nb.更新插件、/nb.升级插件**：更新插件

> 说明：管理服务会同时处理全局状态、群状态、用户状态和插件生命周期，适用于维护与运维场景。
