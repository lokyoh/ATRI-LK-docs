# 插件商店

ATRI 的插件管理入口，可查看商店插件、安装、卸载、更新及重载插件。

## 服务信息
- **服务名**：插件商店
- **说明**：插件商店
- **权限限定**：主人

## 命令列表
- **/插件列表**：查看插件列表及当前版本状态
- **/插件详情**：查看指定插件详情，包括版本、作者和介绍
- **/添加插件**：安装指定插件
- **/移除插件**：卸载指定插件
- **/更新插件**：更新指定插件
- **/检查插件更新**：检查已安装插件是否存在更新
- **/更新所有插件**：批量更新所有已安装插件
- **/重载所有插件**：重新加载全部插件，并重载 RSS 相关插件

> 说明：该服务适合在维护时统一管理第三方插件与内置插件。
