# 钓鱼

## 服务信息

- **服务名**：钓鱼
- **说明**：ATRI的钓鱼插件
- **限定权限**：无

## 命令列表

- **/钓鱼.我的信息**：查看自己的个人信息
- **/钓鱼.成就**：查看个人成就
- **/钓鱼、/抛钩**：抛出鱼钩
- **/收线、/收杆**：鱼上钩后收起鱼线
- **/前往**：前往不同的钓鱼地点.如:湖、河、海
- **/装备**：装备指定的鱼竿、鱼饵或鱼具
- **/自动装备**：自动装备可用装备,默认按加载顺序装备
