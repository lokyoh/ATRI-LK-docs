# 智能体

## 服务信息

- **服务名**：agent
- **说明**：为ATRI-LK项目专门设计的智能体系统，提供AI聊天、记忆管理、用户画像、功能调用等能力
- **限定权限**：主人（MASTER）

## 命令列表

- **/agent.reload**：重新加载agent配置（主人）
- **/agent.总结记忆**：总结所有用户的记忆（主人）

## 功能说明

### 核心能力

智能体系统为聊天插件（lkchat）提供底层AI能力支持：

- **长期记忆**：自动记住与用户的对话内容和重要信息
- **用户画像**：根据交互自动构建用户兴趣和偏好
- **词语解释**：支持自定义词语解释，AI聊天时会参考
- **功能调用**：支持网络搜索、图片识别、日程管理等功能
- **Token统计**：统计模型调用的Token消耗

### 记忆系统

- 记忆会自动总结并存储，在后续对话中可能被引用
- 记忆与用户ID绑定，不同用户的记忆相互独立
- 使用 `/agent.总结记忆` 可以手动触发记忆总结任务

### 模型管理

智能体支持多个AI模型，可以通过配置文件切换：

- 支持OpenAI兼容接口
- 支持Gemini接口
- 支持自定义模型提供商
- 可以为不同任务配置不同模型（chat/tool/image/embedding/tts）

## 配置说明

智能体的配置文件位于 `data/config/plugins/agent_config.json`：

- `max_history`：最大历史消息数（默认30）
- `max_thinking_times`：最大思考次数（默认20）
- `search`：网络搜索配置
  - `enable`：是否启用搜索
  - `provider`：搜索提供商（如tavily）
  - `api_key`：搜索API密钥

模型配置位于 `data/config/system/provider.yml`，可以配置多个模型提供商和模型。

## 注意事项

- 智能体需要配置至少一个可用的聊天模型才能正常工作
- 记忆和画像功能会消耗额外的API调用
- 功能调用需要相应的模型支持（如工具调用模型）
- 建议根据实际需求调整记忆保留数量，过多会增加上下文长度

## 功能说明

### 记忆系统

智能体具备长期记忆能力，可以记住与用户的对话内容和重要信息。记忆会自动总结并存储，在后续对话中可能会被引用。

- 记忆会自动遗忘过旧的内容
- 可以通过命令查看、删除或清空记忆
- 记忆与用户ID绑定，不同用户的记忆相互独立

### 用户画像

智能体会根据与用户的交互自动构建用户画像，包括用户的兴趣、偏好、性格特征等。

- 画像会随着对话自动更新
- 可以通过命令查看或重置画像
- 画像用于个性化回复风格

### 功能调用

智能体支持多种功能调用，包括：

- **网络搜索**：搜索实时信息
- **图片识别**：识别图片内容
- **日程管理**：管理亚托莉的日程安排
- **表情发送**：发送亚托莉表情包
- **词语解释**：解释特定词语或概念

### 模型管理

智能体支持多个AI模型，可以根据需要切换：

- 支持OpenAI兼容接口
- 支持Gemini接口
- 支持自定义模型提供商
- 可以为不同任务配置不同模型

## 配置说明

智能体的配置文件位于 `data/config/agent_config.json`，包含以下配置项：

- `max_history`：最大历史消息数（默认30，包含Agent自己发送的消息）
- `max_thinking_times`：最大思考次数（默认20）
- `search`：网络搜索配置
  - `enable`：是否启用搜索
  - `provider`：搜索提供商（如tavily）
  - `api_key`：搜索API密钥

模型配置位于 `data/config/provider.yml`，可以配置多个模型提供商和模型。

## 注意事项

- 智能体需要配置至少一个可用的聊天模型才能正常工作
- 记忆和画像功能会消耗额外的API调用
- 功能调用需要相应的模型支持（如工具调用模型）
- 建议根据实际需求调整记忆保留数量，过多会增加上下文长度
