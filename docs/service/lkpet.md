# 宠物

## 服务信息

- **服务名**：宠物
- **说明**：赛博宠物养成系统，支持宠物养成、肉鸽爬塔、跑团等玩法
- **限定权限**：无

## 命令列表

### 基础养成

- **/宠物.创建 <性格> <名字> \[设定]**：创建宠物（仅一次）。性格可选：勇敢/胆小/温和/狡猾/忠诚/好奇
- **/宠物.状态**：查看宠物状态与属性
- **/宠物.结算**：手动触发日结算
- **/宠物.喂食 <食物ID>**：喂食宠物（消耗1行动点）
- **/宠物.玩耍**：陪宠物玩耍（消耗1行动点）
- **/宠物.抚摸**：抚摸宠物（不消耗行动点）
- **/宠物.洗澡**：给宠物洗澡（消耗1行动点）
- **/宠物.训练 <属性>**：训练宠物属性 hp/atk/def/spd/mp（消耗2行动点）
- **/宠物.休息**：让宠物休息，恢复疲劳（不消耗行动点）

### 查看信息

- **/宠物.技能**：查看宠物已学会的技能与熟练度
- **/宠物.天赋 \[天赋ID]**：查看或分配天赋点
- **/宠物.传记**：查看宠物的传记与称号
- **/宠物.日志**：查看最近的每日日志
- **/宠物.好感度**：查询宠物亲密度（0-1000）

### 高级功能

- **/宠物.轮回 \[确认]**：查看轮回条件；带"确认"才真正执行轮回
- **/宠物.特权 \[特权ID]**：查看或兑换成就点特权
- **/宠物.改名 <新名字>**：为宠物改名
- **/宠物.设定 <设定>**：修改宠物的聊天人设

### 管理命令

- **/宠物.列表**（管理员）：列出本群所有有宠物的成员
- **/宠物.全部**（主人）：列出所有宠物

### 附加玩法

- **/宠物 <内容>**：与宠物聊天（LLM）
- **/宠物.肉鸽 \[动作]**：肉鸽爬塔玩法，动作包括：开始/继续/进度/撤退（消耗行动点：入场3点+每层1点）
- **/宠物.跑团 \[动作]**：跑团（COC风格d100），动作包括：建卡/卡/重掷/开团/检定/进度/结束

## 功能说明

### 宠物养成系统

所有宠物共用一套模型，个体差异来自性格与随机资质。

- **每人仅一只**：不可更换、不可多养、不可交易
- **天为基本单位**：年龄、寿命、状态衰减、行动点重置全部以个人日推进
- **轮回必须主动确认**：日结算只会提示条件，绝不自动终止或重置宠物

### 肉鸽爬塔

100层 = 5个区域 × 20层，包含：
- 青草平原 → 迷雾森林 → 熔岩洞窟 → 冰封王座 → 深渊之巅
- 每区域第10层为固定遗物奖励层（三选一）
- 每区域末层为随机首领战
- 95件遗物系统（仅本局生效）
- ATB战斗机制：速度决定出击频率

### 跑团系统

COC风格d100跑团，包含：
- 六维属性（STR/CON/DEX/POW/INT/APP）
- 9个剧本：单人5个、多人3个、短团1个
- d100六档判定（大成功/极难/困难/常规/失败/大失败）
- 混合GM：模板+LLM裁定，LLM失败自动回退模板

## 配置说明

插件配置文件位于 `data/config/plugins/宠物_config.json`：

- `enable`：养成系统总开关（默认True）
- `settle_notify`：日结算后是否推送通知（默认True）
- `settle_check_hour` / `settle_check_minute`：每日检查日结算的时间（默认0/0）
- `notify_groups`：接收通知的群号列表（默认空）
- `tutorial_enabled`：是否启用新手引导（默认True）
